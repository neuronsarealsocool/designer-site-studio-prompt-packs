## 0. The task

Build a single-page, desktop-first marketing site for a fictional product, **Companion OS** ("the operating
system that sees you"). The page is a **point-cloud bust of a human head and shoulders** (≈ 60 000
points) rendered with three.js on a see-through canvas fixed behind the page. The bust reacts to the
pointer (turns its whole body toward it, its points stir like a liquid, a colour gradient follows the
pointer) and is choreographed by scroll through four parts:

1. **Hero** — the bust in front of a huge pixel-font title "HELLO, I'M HERE", a note in the bottom-left corner.
2. **OS** (pinned) — the whole dark screen *zooms out* into a rounded frame on a light lavender ground; seven
   dark-glass UI widgets fly in from "the camera" around it, hold, then fly back out as the frame zooms back
   in to full screen.
3. **Memory** — the bust glides into the top-left corner, magnified 3.3×, turned to look right; text and
   glass panels on the right.
4. **Agents** — the bust bursts into pixel dust, travels as a cloud, and re-forms in the top-right corner,
   looking left; text and panels on the left.

### Deliverable and stack

### House rules for the code

- Comments in plain English sentences explaining *why*, at the top of every module and above each constant.
- rAF loops run **on demand** only (woken by scroll / resize / pointer; they sleep when everything has
  settled; they pause on `visibilitychange`).
- All springs: unit mass, stiffness `k`, damping `c`, **semi-implicit Euler in substeps of ≤ 1/240 s**,
  `dt` clamped to `[0, 0.25]` s; a spring snaps to its target and reports "still" when
  `|t − x| < eps` and `|v| < eps·10`.
- Respect `prefers-reduced-motion` everywhere (details per section).
- No strokes, no drop shadows (one exception: the light-mode lift on OS widgets), no icon fonts (glyphs are drawn in CSS).

squircle with **60 % corner smoothing** built from its own computed `border-top-left-radius` and size
(the figma-squircle construction by phamfoo: per corner a cubic, an arc, a cubic; smoothing reduced to

`ResizeObserver` callback. The CSS `border-radius` stays as the no-JS fallback.

## 6. The bust renderer (`lib/cloud.js`)

### Loading and placement

- `loadPCD(url)`: `PCDLoader().loadAsync` → `geometry.rotateX(π)`, `rotateY(0.05)` (FACE_YAW), `rotateX(0.19)` (FACE_PITCH); compute the box;
  centre y and z on the box, but **x on the head line**: split the top 45 % of the height into 48 rows, take each row's
  `(minX+maxX)/2`, sort, take the median. Translate so that point is the origin. Return the raw `Float32Array`.
- Constants: `FOV 30°`, `SIZE 0.78` (bust height / viewport height), `BLEED 0.07` (base sinks this share of the height below the bottom),
  `WIDE 1.3` (max width in viewport widths), `POINT_SIZE 0.005`, `HEAD_Y 0.10` (head centre above the bust centre, model units),
  camera near/far `0.01 / 40`.
- `fit()`: `view = max(size.y / SIZE, size.x / (WIDE·aspect))`; camera at `z = view/2 / tan(FOV/2)`, looking at origin;
  `headInRig = (0, HEAD_Y − box.min.y, 0)`; `heroY = (−view/2 − BLEED·view + headInRig.y) / (view/2)`;
  `unitsPerPx = view / host.clientHeight`; set `--bust-top` on `<html>` to `(1 + BLEED − size.y/view)·100 %` (2 decimals);
  re-`place()` the last pose with its last gaze/anchor.
- **Rig**: a `Group` with `rotation.order = 'YXZ'`, pivot at the bust's base; the points mesh sits inside at `position.y = −box.min.y`.
- `place(pose, gaze=[0,0,0], anchor=0)`: `pose = {x, y, scale, yaw, pitch, roll}` (head target in NDC).
  Scale the rig; set rotation `pose + gaze·anchor`; `lift = headInRig·s` rotated by it; `half = (camera.z − lift.z)·tan(FOV/2)`;
  `rig.position = (x·half·aspect − lift.x, y·half − lift.y, 0)`; then set the final rotation `pose + gaze` (full gaze).
  `localPerPx = unitsPerPx / s`; `uUnits = localPerPx`; `uSize = POINT_SIZE·s`. Project the head (`cloud.head = (0, HEAD_Y, 0)`) to get
  `headNdc`; `headPx = headSize·s / unitsPerPx` (headSize: x-span and height of the points above `HEAD_Y − (top − HEAD_Y)`);
  `uHead = headNdc`, `uHeadR = max(headPx.h / clientHeight, 1e-3)`. Call `cloud.onPlace?.()`.

### Renderer and glow

- `WebGLRenderer({ antialias:false, alpha:true })`, pixel ratio `min(devicePixelRatio, 2)` (never changes), clear colour black alpha 0, no scene background.
- `EffectComposer` on a `HalfFloatType` target (no MSAA): `RenderPass` → `UnrealBloomPass(strength 0.020, radius 0.9, threshold 0)` → `OutputPass`.
- Patch the bloom composite: remove `bloomStrength` from `vec3 bloom = 3.0 * bloomStrength * (` and before `float bloomAlpha` insert
  `float lum = max(dot(bloom, vec3(.2126,.7152,.0722)), 1e-5); bloom = bloomStrength * bloom * (pow(lum, 0.60) / lum);` (hue kept, no tint).
- Bloom at CSS resolution: replace the 5 separable blur materials with kernels `[3, 5, 7, 9, 11]`; override `bloom.setSize(w,h)` to call the
  original with `round(w/ratio), round(h/ratio)`; patch the high-pass to average 4 taps at `vUv ± uSrc` where `uSrc = (ratio/2/w, ratio/2/h)`.
- Patch `OutputPass` after the `#ifdef SRGB_TRANSFER … #endif` block: `gl_FragColor.a = max(gl_FragColor.a, max(r, max(g, b)))`
  (so the faint haze survives premultiplied compositing over the page).
- `ResizeObserver` on the stage → `renderer.setSize(w, h, false)`, composer size and ratio, camera aspect, `uViewport = (w, h)`, `fit()`, render.

### Particles (`grains` ShaderMaterial, `DoubleSide`)

One instanced quad (corners ±1, indices `0 1 2 2 1 3`) per point; `aHome` = position, `aRef` = the point's texel centre in a
square texture of side `2^ceil(log2(sqrt(n)))`. `frustumCulled = false`.

Uniforms: `uState, uFlow` (liquid textures; a 1×1 zero float texture until the liquid exists), `uOrigin, uSpan` (wake field), `uUnits`,
`uSize`, `uStreak 0.8`, `uViewport`, `uCenter (0, 0.10)`, `uRadius 0.40`, `uGrain 0.335`, `uScatter 0`, `uDim 0`, `uHead`, `uHeadR`, `uTime`.

Vertex shader:
- `st = texture(uState, aRef)` (xy offset px, zw velocity px).
- Dust: `r = fract(sin(vec3(dot(aRef,(12.9898,78.233)), dot(aRef,(39.3468,11.135)), dot(aRef,(73.156,52.235)))) * (43758.5453, 24634.6345, 9631.7453))`;
  `k = uScatter²`; `fling = normalize(r − .5 + 1e-3)·(.35 + .65·r.x)·0.05`; `drift = (sin(uTime·.7 + r.y·2π), cos(uTime·.6 + r.z·2π), 0)·0.01`;
  `vDrop = step(1 − uScatter·0.7, r.z)`; `p = aHome + (st.xy·uUnits, 0) + (fling + drift)·k`.
- Streak: project `p` and `p + velocity·uUnits`; `v` = their screen delta in px; `len = min(|v|·1.25, 18)·uStreak`;
  half side `h = uSize·(1 − 0.45·uScatter) / (2·c.w) · .5·uViewport.y`; `vFade = smoothstep(0, 1.5, len)`;
  axis = `normalize(mix((1,0), dir·sign(dir.x), vFade))`; quad corner `lc = position.xy·(h + len/2, h)`; offset
  `axis·lc.x + perp·lc.y − dir·len/2`; `vTail = (dot(off, −dir) − h) / max(len, 1e-3)`; add the offset in clip space. `vNdc = c.xy/c.w`.
- Colour: `t = distance(aHome.xy, uCenter) / uRadius`; `vGrad = ramp(t)`, `vTouched = touched(t)`;
  `vInk = clamp(texture(uFlow, clamp((p.xy − uOrigin)/uSpan, 0, 1)).w, 0, 1)`.
- The ramps are generated GLSL: start at the first stop, then for each stop `c = mix(c, stop, clamp((t − prev)/(pos − prev), 0, 1))` (flat outside, like CSS).
  - `touched` stops (full design colours): `0 % #FFFFFF`, `32 % #C8A9EB`, `100 % #E2E626`.
  - `ramp` stops = the same with OKLCH chroma × **0.6** (`soften`, lightness and hue kept, via OKLab; gives ≈ `#C2B0D7` and `#DFE389`).

Fragment shader:
- `discard` if `vDrop > .5` or `clamp(vTail,0,1)·.55·vFade > hash(gl_FragCoord.xy, (12.9898,78.233), 43758.5453)` (dithered tail).
- `col = mix(vGrad, vTouched, vInk·0.6)`; film grain: `col = mix(col, overlay(col, vec3(hash(fragCoord, (39.3468,11.135), 24634.6345))), uGrain)`
  with the standard overlay blend.
- Veil (depth on the text screens): `r = length((vNdc − uHead)·(aspect, 1)) / uHeadR`; `edge = smoothstep(.3, 1.3, r)`;
  `dir = −clamp(uHead.x/.3, −1, 1)`; `side = smoothstep(−.2, 1, dir·(vNdc.x − uHead.x))`;
  `col *= (1 − uDim·0.1)·(1 − uDim·0.6·edge)·(1 − uDim·0.45·side)`.
- Output `vec4(srgbToLinear(col), 1.)` then `#include <colorspace_fragment>`.

## 7. Motion of the bust (`lib/scroll.js`, `lib/cursor.js`, `lib/liquid.js`)

### Scroll → pose (`scroll.at(scrollY, heroY)`)

Measure the tops of `[data-screen="os"]`, `memory`, `agents` (`getBoundingClientRect().top + scrollY`) on body resize; `vh = innerHeight`.
`smooth(a, b, v)` = smoothstep; `around(top, [a, b]) = smooth(top + a·vh, top + b·vh, y)`.

```
LEFT  = { x: −0.66, y: 0.64, scale: 3.3, yaw: 0.48, pitch: 0.03, roll: −0.28 }
RIGHT = { x: +0.66, y: 0.64, scale: 3.3, yaw: −0.48, pitch: 0.03, roll: +0.28 }
CENTER_DROP = 0.08; OS_IN = [0.12, 0.8]; OS_OUT = [2.2, 3.2]; TO_LEFT = [−1, −0.2]; WINDOW = [−0.6, 0.1]; CONDENSE = 0.42

inOS  = around(osTop, OS_IN);  outOS = around(osTop, OS_OUT);  toLeft = around(memoryTop, TO_LEFT)
u       = clamp((y − (agentsTop + WINDOW[0]·vh)) / ((WINDOW[1] − WINDOW[0])·vh), 0, 1)
side    = smooth(0.3, 0.7, u)
scatter = smooth(0, 0.4, u) · (1 − smooth(0.6, 1, u))
centre  = { x: 0, y: heroY − CENTER_DROP·inOS·(1 − outOS), scale: 1, yaw: 0, pitch: 0, roll: 0 }
for each key: screen = LEFT + (RIGHT − LEFT)·side;  pose = centre + (screen − centre)·toLeft
pose.scale *= 1 − CONDENSE·scatter
return { pose, scatter, hero: 1 − inOS, dim: toLeft }
```

### The loop (`initCursor(cloud, scroll)`, after the model loads)

- Springs: every pose key on `POSE {k 30, c 11}`; `dust` on `{k 26, c 10}`; hero weight and `dim` on POSE; gaze `yaw, pitch` on
  `TURN {k 110, c 15}`, `roll` on `SWAY {k 45, c 9}`; float `fx, fy` on `FLOAT {k 10, c 6}`; gradient centre `gx, gy` on `GLOW {k 18, c 8}` (eps 1e-5; others 1e-4).
- Each frame: read the canvas's on-screen rect from `cloud.stageBox` (no layout reads: `width = W·s`, `left = (W − width)/2 + tx`, same for y);
  set targets from `scroll.at`; step springs (reduced motion: snap, no dust); if the pointer is on, recompute the gaze target.
- **Gaze (hero):** ray from the camera through the pointer (using that rect), intersect the plane `z = D` (`D = 0.41`);
  eye = head + points.position + rig.position; `yaw = clamp(atan2(hit.x − eye.x, D), ±0.6)`, `pitch = clamp(atan2(eye.y − hit.y, D), −0.35, +0.3)`;
  targets multiplied by the hero weight; `roll = −yaw·0.18`.
- **Float (screens):** `fx = clamp(px/innerWidth·2 − 1)`, `fy = clamp(1 − py/innerHeight·2)`; weight `f = 1 − hero`.
- `cloud.place({ x: pose.x + fx·0.035·f, y: pose.y + fy·0.05·f, scale, yaw: pose.yaw + fx·0.07·f, pitch: pose.pitch − fy·0.04·f, roll }, [pitch, yaw, roll], f)`.
- Uniforms: `uScatter = dust`, `uDim = dim`, `uTime = clock (s)`.
- **Gradient centre:** pointer ray into the points' local space ∩ plane z = 0 → clamp to the box ± 0.1 → `gx, gy` targets; head when the pointer is off.
- Stays awake while any spring moves, dust > 1e-3, or the liquid is running. Starts with `snap()` (a mid-page load starts in its pose).
- Pointer input only under `(hover: hover) and (pointer: fine)` and no reduced motion, `pointerType !== 'touch'`. `pointerleave` on `<html>`
  or `pointerout` with no `relatedTarget` eases gaze back to 0. If either media query flips to "off" mid-session: reset everything to rest at once.

### Liquid (`lib/liquid.js`, created lazily on the first live pointer move)

Port of the cursor interaction from 21st.dev's "Sculpture Hero", at half force. `GPUComputationRenderer(side, side)`, `HalfFloatType`.
Home texture (Float, RGBA): `(x, y, random(), 1)` per point. Wake field covers a square of local xy:
`span = max(box w, box h) + 2·0.15`, `origin = box centre − span/2`. Two variables: `flow` (depends on itself, linear filter) and
`state` (depends on itself and flow).

Per frame (from `cursor.js`), with `f = clamp(dt·60, .25, 3)`:
- Eased pointer: `m += (p − m)·(1 − (1 − 0.22)^f)`; presence eases toward 1 at 0.1 / toward 0 at 0.035 (same per-frame formula);
  a pointer still for 1500 ms counts as gone; the sim keeps running 270 frames after presence hits 0.
- Wake velocity: local-xy pointer delta / localPerPx / f, clamped ±60, smoothed `wake += (v − wake)·.5`; passed as `wake/40` clamped ±1.
- `time += f/60·(1 + presence·1.6)`.
- Uniforms: `uMouse` (local xy), `uVel`, `uPresence`, `uUnits = localPerPx`, `uDecay = .968^f`, `uInkDecay = .97^f`, `uDt = f`, `uTime`,
  `uRadius 150`, `uInkRadius 110`, `uStrength 0.5`, `uSpread 1`, `uTurb 0.6`, `uReturn 1.2`.

FLOW shader (xy velocity −1…1, z energy, w ink):
```glsl
vec2 suv = uv - texture2D(flow, uv).xy * texel * 2.5;
vec4 c = texture2D(flow, suv) * .52 + .12 * (4 neighbours of suv);
vec2 d = (uOrigin + uv * uSpan - uMouse) / uUnits;
float f = exp(-dot(d,d) / (uRadius*uRadius)) * uPresence;
v += uVel * f * .22;  p = max(p, f * clamp(length(uVel) * 2.5, 0., 1.));
v *= uDecay; p *= uDecay; v = sign(v) * max(abs(v) - 1.2/127., 0.); p = max(p - 1.2/255., 0.);
ink = max(max(c.w * uInkDecay - .002, 0.), exp(-dot(d,d) / (uInkRadius*uInkRadius)) * uPresence);
gl_FragColor = vec4(clamp(v, -1., 1.), p, ink);
```

SIM shader (xy offset px, zw velocity px), skipping texels with `home.w <= 0`; `sd = home.z`, `light = .45 + sd·1.1`:
```glsl
vec2 p = hm.xy / uUnits + off;
vec4 fl = texture2D(flow, clamp((hm.xy + off * uUnits - uOrigin) / uSpan, 0., 1.));
vec2 toM = p - uMouse / uUnits; float r2 = dot(toM, toM);
float f = exp(-r2 / (uRadius*uRadius)) * uPresence; vec2 n = toM * inversesqrt(r2 + 1.);
float e = clamp(fl.z * 2. + f, 0., 1.);
acc  = n * f * 1.25 * uStrength * uSpread * light;
acc += vec2(-n.y, n.x) * f * 1.45 * uStrength * uSpread * (.4 + sd);
acc += (fl.xy * 42. * uSpread * light - vel) * e * .08;
vec2 q = p * .0095 + vec2(uTime * .35, -uTime * .2);
acc += (curl(q) + .5 * curl(q * 2.3 + 7.1)) * e * 1.2 * uSpread * uTurb * light;
acc -= off * (.006 + .02 * uReturn) * (.65 + sd * .7);
vel += acc * uDt; vel *= pow(mix(.93, .955, e), uDt); off += vel * uDt;
if (dot(off,off) < .0004 && dot(vel,vel) < .0004) { off = vec2(0.); vel = vec2(0.); }
```
`curl` = 2D curl of a quintic value noise (`hash(p): p = fract(p·(123.34, 456.21)); p += dot(p, p + 45.32); fract(p.x·p.y)`), epsilon .35.
After each compute, point `uState` / `uFlow` of the grains at the current render targets.

### Layout

  `.frame-head__title`: margin 0, `var(--t-l)` / `var(--lh-l)` / `var(--tr-l)`, `--ink-1`; its span block `--ink-3`.

### Progress

`s = clamp((scrollY − osTop) / innerHeight, 0, END)` with `PIN_VH 1.7`, `HOLD 0.5`, `OUT_VH 1`, `END = 3.2`. The displayed `p.x` follows
`s` on a spring `{k 26, c 10}` (reduced motion: instantly). Then:
```
q = clamp(p.x / 1.7, 0, 1)                        // IN
o = clamp((p.x − 1.7 − 0.5) / 1, 0, 1)            // OUT
seg(v, [a,b]) = clamp((v − a)/(b − a), 0, 1)
inOut(t) = t < .5 ? 4t³ : 1 − (−2t + 2)³/2;  out(t) = 1 − (1 − t)⁴;  expo(t) = t ≥ 1 ? 1 : 1 − 2^(−10t);  smooth = smoothstep
```
- **Hero exit:** toggle `html.is-hero-out` when the raw `s > 0.05`; remove it when `s ≤ 0.03` (hysteresis).
- **Frame:** `k = inOut(seg(q, [0.06, 0.5]))·(1 − inOut(o))`; `scale = 1 − (1 − 0.56)·k`; framed = `q > 0 && o < 1` → class `is-framed`.
  `stage.style.transform = translate(fx, fy) scale(scale)` (about the window's centre, so it ends centred at 22–78 vw × 22–78 vh),
  `border-radius = 28·k/scale px` (28px as seen). Frame drift `fx, fy = drift·(−4)·k` px. Write `cloud.stageBox = {s, tx, ty}` and `cloud.framed`.
  When not framed: clear transform and radius.
- **Ground:** `g = seg(q, [0.1, 0.42])·(1 − seg(o, [0.3, 0.9]))`; `html.style.backgroundColor = rgb(lerp(0,0,0 → 232,229,239, g))` (empty when g = 0).
  `.hd.is-light` when `g > 0.5`.
- **Headline:** `e = out(seg(q, [0.2, 0.44]))·(1 − smooth(seg(o, [0, 0.4])))`; opacity `e`;
  transform `translateY((1 − e)·24px) scale(1/0.56)`; `filter: blur((1 − e)·10px)` while `0 < e < 1`.
- **Widgets** (`.ow`, each with `data-at`): `K0 3.6`, `LEN 0.22`, `OUT_LEN 0.45`, blur 44px, `BLUR_EASE 0.55`, `GLASS_K 1.5`.
  Exit order: sort by `data-at` descending; `outAt_i = i·(1 − 0.45)/(n − 1)`. Per widget:
  ```
  t = seg(q, [at, at + 0.22]);  tOut = seg(o, [outAt, outAt + 0.45])
  e = expo(t);  eOut = tOut^2.2
  k = 1 + (K0 − 1)·((1 − e) + eOut)                         // nearer the eye = bigger and further from centre
  here = e·(1 − tOut)
  x = cx·(k − 1) + springX·drift·here;  y = cy·(k − 1) + springY·drift·sway·here   // cx, cy = widget centre − window centre
  opacity = smooth(clamp(t/0.45, 0, 1))·(1 − smooth(clamp((tOut − 0.3)/0.7, 0, 1)))
  blur = flying ? 44·((k − 1)/(K0 − 1))^0.55 : 0           // flying = 0<t<1 or 0<tOut<1
  glass = clamp((1.5 − k)/(1.5 − 1), 0, 1)
  ```
  Write `opacity`, `transform: translate(x,y) scale(k)`, `filter: blur()` (only if > .05), `--glass = glass`, `--solid = 1 − glass`;
  toggle `.has-glass` when `glass > 0`. Only write when the composed string changes.
  On landing (`t === 1`): the chart's `.minibars` gets `is-grown`; the composer types its `data-type` text
  (first after 350ms, then 34ms per character, removing `is-empty`). On leaving (`t < 1`): undo (bars shrink, text back to "Ask Companion anything…", `is-empty`).
  Reduced motion: widgets only fade (`e`, `eOut` and opacity step), glass = 1, text appears whole.
- **Pointer drift:** pointer position in −1…1; frame drift spring `{k 16, c 8}`; each widget its own spring with stiffness
  `7 + 13·(drift − minDrift)/(maxDrift − minDrift)` and `c = 2·√k·0.95`; vertical shares `SWAY_Y = [1, .7, 1.15, .8, 1.2, .6, .9]` by DOM index.
  Ignore the pointer while `p.x ≤ 0`, on touch, or under reduced motion.
- rAF on demand (scroll, resize, pointermove); stops when `p` and all drift springs settle. Re-measure widget centres
  (`offsetLeft + offsetWidth/2 − innerWidth/2`, same for y) on resize. A load mid-section starts at `p.x = s`.

### Reveal (`lib/reveal.js`)

- Bars: build one `<i>` per value with `--h`, `--j`; class `now` at index `now`, `on` if before it and value > 10. Axis spans; "Now" gets `is-now`.

## 10. Bottom veil (`lib/veil.js`)

A fixed strip `left:0; right:0; bottom:0; height:16vh; z-index:2; pointer-events:none`, appended to `body`, containing 6 absolutely filled layers with
`backdrop-filter: blur(.75 | 1.5 | 3 | 6 | 12 | 24 px)`. Layer `i` (of n = 6) is masked with
`linear-gradient(to bottom, transparent i/n, #000 (i+1)/n, #000 (i+2)/n, END (i+3)/n)` (percentages capped at 100 %), where END is `#000` when
`i + 3 > n`, else `transparent`. No tint. Present on every screen.
