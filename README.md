# Scroll Site Studio source backups

Private, independent online snapshots of reference packs used by Scroll Site Studio.
These are backups for the repository owner, not a public media library or a grant
of redistribution rights. Backing up an asset does not approve it for a website.

## Frostwood

The 2026-10-21 snapshot contains the prompt document, original image/reference ZIP
and WordPress-theme ZIP. Its manifest records source URLs, sizes and SHA-256 hashes.
Keep snapshots immutable; add a new dated version when a source changes. Preserve
source attribution and existing notices. No API keys or account credentials belong here.

## Layer

The 2026-10-22 snapshot preserves the original asset ZIP, WordPress-theme ZIP and
hero-reference PNG, plus DOCX and Markdown exports of the native Google prompt
document. Five file sizes and SHA-256 hashes are recorded in the manifest.

## Horizon Estates

The 2026-10-23 snapshot preserves all 15 original PNGs in their Orange/Purple
folders and DOCX/Markdown exports of the native Google prompt document. The
manifest records all 17 sizes/checksums plus image dimensions and alpha-channel
inspection. No completed theme or code archive was supplied.
